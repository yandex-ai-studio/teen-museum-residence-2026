Создай статическое веб-приложение для мобильного устройства с помощью mobile-web-app skill, и размести его в sourcecraft pages с помощью соответствующего скилла. 
Приложение должно обеспечивать навигацию по экспонатам музея, информация о которых содержится в data\pushkin-enrich.json. Используй нижнее меню чтобы сделать несколько типов навигации: по категории category, по тегам, по периоду, по автору, по локации в музее. Также сделай режим навигации, когда по текущему экспонату легко перейти в ближайшим в этом же зале / здании. Исследуй весь JSON файл, чтобы определить возможные локации, теги и т.д. Категории прописаны в файле data\images\generated\images.json, вместе с картинками, которые можно использовать как thumbnails. Картинки экспонатов доступны в интернет, адрес указаны в pushkin-enrich.json. Для описаний экспонатов всегда используй поле xdescription с более коротким описанием.
